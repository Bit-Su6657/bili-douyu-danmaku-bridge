# B站弹幕聚合推送斗鱼直播油猴插件

一个基于 Tampermonkey 的跨标签页弹幕工具：在 B 站直播间采样弹幕，聚合到斗鱼直播间进行滑窗统计、聚类和热点检测，并按固定周期或爆发策略自动发送。

## 功能

- 从 B 站直播聊天区域采样弹幕
- 通过 Tampermonkey 存储同步到斗鱼直播间
- 支持精确文本聚类和循环归一化后的有序重合聚类
- 支持主滑窗、独立爆发最近窗口和基线窗口
- 支持固定周期发送和“固定周期 + 爆发提前”两种策略
- 支持 Top1、TopN 轮换、TopN 随机和自定义列表发送
- 支持发送前缀、后缀和正则黑名单
- 提供爆发热点调试面板
- 主面板支持拖动、最小化和最小化图标
- 视频全屏或斗鱼网页最大化时自动隐藏最小化图标

## 安装

1. 安装 [Tampermonkey](https://www.tampermonkey.net/) 浏览器扩展。
2. 打开 [安装脚本](https://raw.githubusercontent.com/Bit-Su6657/bili-douyu-danmaku-bridge/main/live-danmaku-bridge.user.js)。
3. 在 Tampermonkey 安装页面确认安装或更新。

## 使用

1. 打开一个 B 站直播间标签页，确认采样面板开始统计弹幕。
2. 打开一个斗鱼直播间标签页，等待采样来源登记和弹幕同步。
3. 在斗鱼面板中设置主滑窗、聚类方式和相似度。
4. 在“弹幕发送”中配置来源、发送策略、间隔和黑名单。
5. 先使用“发送一次”验证输入框和发送按钮定位是否正常。
6. 确认无误后点击“开始发送”。
7. 需要查看热点判断过程时，展开“爆发热点检测调试”并使用模拟启动。

## 发送策略

### 固定周期

按照当前主滑窗的聚合榜单选择弹幕，并按最小/最大间隔随机延迟发送。

### 固定周期 + 爆发提前

保留固定周期发送，同时使用独立的爆发检测窗口监测热点。爆发检测的聚类基底固定为最近 120 秒，最近窗口和基线窗口由爆发设置控制；主滑窗只影响固定周期部分，不参与爆发阈值计算。

## 黑名单

黑名单每行一条规则：

- 纯文本使用整条弹幕全匹配，忽略英文大小写
- 含正则语法的规则自动按正则表达式处理
- 支持 `/表达式/flags` 显式正则写法
- 非法正则自动退化为纯文本全匹配

示例：

```text
？
```

只匹配内容正好为 `？` 的弹幕。

```text
(?:？+|\?+)
```

匹配包含连续全角问号或连续 ASCII 问号的弹幕。

## 数据与权限

脚本使用以下 Tampermonkey 能力：

- `GM_setValue`
- `GM_getValue`
- `GM_addValueChangeListener`
- `GM_info`

脚本不会读取或导出账号密码、Cookie、访问令牌或浏览器凭据。跨标签页同步仅通过 Tampermonkey 存储完成。

## 已知限制

- 发送功能依赖斗鱼页面当前的聊天输入框和发送按钮结构，页面改版后可能需要适配。
- 浏览器后台标签页可能被节流，实际发送时间可能晚于设定时间。
- 复杂的用户正则可能影响页面响应，请避免灾难性回溯表达式。
- 自动发送可能受到直播间规则限制，请自行确认使用场景和风险。
